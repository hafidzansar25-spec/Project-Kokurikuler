Pengembang Aplikasi

Informatika & Matematika — Projek Smart Ecolife

Aplikasi Eco-Tracker dirancang untuk membantu transparansi dan efisiensi pengelolaan sampah sekolah. Aplikasi ini menggabungkan prinsip algoritma pemrograman web modern serta pemodelan statistik matematika dasar.

Teknologi Frontend: HTML5, CSS3 Custom Properties, JavaScript ES6+, html2pdf.js, & Chart.js
Arsitektur Data: Multi-Page Client Single Page App (SPA) dengan LocalStorage Persistence & Dynamic PDF Renderer
